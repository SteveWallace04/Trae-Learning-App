# 本地程序

## 学习指导与材料保存（2026-09-22）

guidance.py 维护独立指导会话、有限近期上下文、课堂引用、结构化提案与确认接口；记录位于 data/guidance，不进入课堂会话列表与断点来源。learning_materials.py 负责新安装初始化、版本核对、持久变更记录、失败恢复和撤销；读材料前先恢复待完成变更。storage.atomic_write 保留传入的换行形式，以保持版本和恢复比较一致。

已实现 main.py：提供页面、健康接口、设置接口、聊天流、停止与记录恢复。运行 python -m app.main 在 127.0.0.1:8000 启动服务。
目前只支持源码运行；网页文件位于源码仓库 web/，未制作包含资源的独立安装包。

模块分工：
- main.py：启动 FastAPI、提供网页和接收请求。
- model.py：调用 DeepSeek，将回答逐段传回。
- storage.py：原子替换写入 .env、会话 JSON 和当前选择文件；列出历史并从第一条问题生成标题，消息保留角色、编号、状态和关联问题。
- context.py：按本机配置加载应用维护的 10 份材料（旧安装可只读外部来源），读取已保存的应用计算机断点，加入实际能力说明，保存请求材料快照；原文范围见 docs/teaching-context.md。

一次聊天：读取原文并准备教学上下文与完整问答 → 保存材料快照、用户消息和待生成记录 → 调用模型 → 逐段传回 → 保存回答 → 通知网页保存结果。读取或保存失败不调用模型。
main.py 用一个生成任务处理当前回答，队列只负责把增量传给网页；停止或断开连接时取消任务并保存片段。测试可注入临时资料路径和模拟模型，不读取真实密钥。
中断的回答标记为未完成，不伪装成完整回答。

会话管理：GET /api/conversations 列出历史，POST 同一路径新建，POST /api/conversations/{id}/select 切换。新建、切换、聊天和重试保存都带页面当前 conversation_id，服务核对后才操作，拒绝过期窗口写入。当前选择保存至 data/current-conversation.json；旧版没有此文件时沿用最近修改会话的恢复方式。

切换成功后才替换内存中的当前会话，生成中或保存失败时拒绝切换。新建前保存旧选择，新文件与新选择依次落盘；若新文件已保存而选择写入失败，保留旧选择，列表可能多出一个可稍后打开的空白对话。打开历史中未完成的回答时将其标记中断。没有数据库或多会话并行生成。

已实现断点流程：读取旧断点和当前对话 → 请求模型整理四段 Markdown 草稿 → 用户编辑确认 → 原子保存并展示。breakpoints.py 负责提示装配、草稿/记录格式及文件读写；main.py 提供读取、整理、取消、保存和来源接口。草稿保留在服务内存，保存核对草稿编号、旧版本和消息位置，失败不覆盖旧记录。
格式正确不代表学习判断正确，用户仍能纠正。

一个本地服务同时提供网页和接口，默认只监听本机。密钥由后端读取，不写进聊天或返回给模型作为对话内容。
具体接口和数据字段在实现相应功能时确定，不提前创建空实现。


代码练习：practice.py 提供 /api/practice/{conversation_id} 读取、/save 草稿版本核对与原子保存、/run 启动和 /stop 停止；挂载在原 FastAPI 服务中。草稿只保存应用 data/practice 下，一份对话文件包含 C、Java 代码和输入。为保证只有代码的对话也可恢复，首次保存草稿时会保存尚未落盘的空对话；有练习草稿的空聊天可以新建另一对话。

运行使用后台线程，不阻塞聊天事件循环。每阶段由 practice_worker.py 等待父服务发送参数；父服务先把 helper 加入 process_job.py 的 Windows Job Object，再允许 helper 启动编译器或程序，子进程继承 Job。Job 关闭时清理进程树；这是生命周期控制而非文件或网络隔离。固定工具名称通过 PATH 解析，命令以参数列表传入，不通过 shell 拼接代码。编译 30 秒、执行 10 秒，每阶段输出总上限 16 KiB。临时目录不在原学习项目。普通聊天可以与运行并存，切换会话/整理断点需先结束运行。

运行结果包含当次代码、输入、命令、编译与运行输出/退出码，每对话只保留最近一次于服务内存。用户主动放进聊天后作为用户消息保存，模型没有直接执行权限。没有模型调用、掌握评分或自动学习记录写入。

本轮只做静态阅读，未运行验证；Windows 进程生命周期、编译器兼容、页面交互和失败恢复都尚待实际使用确认。


learning_materials.py：显式一次迁移和三个固定材料标识的读写。迁移逐字节复制 10 份材料，完整目录就位后切换相对来源；不覆盖既有目录或应用断点。GET/POST /api/materials/{profile|teaching|goals} 仅操作已迁入应用的文件，保存核对内容哈希并原子替换。同步读写段无 await，单进程内检查和保存不中途交错。请求快照继续独立存档。当前机器迁移已完成，但编辑接口未运行测试。

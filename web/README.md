# 网页

已实现：聊天主页面、DeepSeek 设置、逐段回答、停止、失败重试、消息恢复和保存失败提示。未配置密钥时禁止发送。

现有文件及后续职责：
- index.html：聊天区域、输入框、设置面板。
- style.css：浅色界面、易读的文字宽度和代码展示。
- app.js：读取设置和会话，接收按行 JSON 消息流，更新页面并处理停止、重试和保存失败。

已实现的交互约定：
- 新建对话、历史列表与切换；标题取第一条问题，当前对话高亮。窄窗口把历史列表放在聊天上方。
- 生成或保存失败时不能切换；同一页面内按对话暂存未发送草稿，刷新不保留草稿。
- Enter 发送，Shift+Enter 换行；中文输入法选字时不误发送。
- 等待、生成、失败和已停止状态明确显示；失败保留问题并可重试。
- 生成时避免重复提交；代码块保留缩进并可复制。
- 用户在底部时跟随回答滚动，查看旧消息时不强制拉回。
- 设置面板接收 DeepSeek 配置，密钥掩码显示；后端保存密钥，不嵌入前端代码。
- 最后选中的聊天由后端恢复；只有保存正常时才显示保存成功。请求携带对话编号，防止其他窗口切换后写错聊天。
- 第一阶段不展示尚未实现的断点或学习观察功能。

网页负责操作与展示，教学材料选择和文件保存由本地程序负责。

vendor/ 内固定版本的 marked 和 DOMPurify 在本地加载；生成中按原文显示，完成或停止后渲染安全的 Markdown。代码可复制，不执行模型提供的 HTML、脚本或加载外部图片。


practice.js 负责可收起的 C / Java 练习面板、Tab/Enter 缩进、草稿自动保存、运行状态轮询、停止和运行快照放入聊天；app.js 在切换对话前等待草稿保存，启动由 practice.js 完成依赖初始化后触发。宽屏旁排，窄屏放在聊天下方。运行和插入代码均由用户点击触发；模型代码不会自动执行。草稿保存失败保留页面编辑，关闭有未保存内容的页面会触发浏览器离开提示。未做浏览器验收。

material-editor.js：当前教学材料预览的三份材料提供编辑入口；历史快照无编辑入口。独立弹窗编辑 Markdown，保存携带读取版本，冲突/失败保留文本；关闭和刷新提示未保存修改。保存后刷新预览，下一轮请求重新读取。网页交互尚未验收。

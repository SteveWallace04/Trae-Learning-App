# Trae-Learning App

本地 AI 编程学习应用：通过网页学习，保存聊天和认知断点，下次从具体问题继续。

**当前状态：已实现本地聊天、学习断点和 C / Java 练习区。10 份原文材料已完整迁入应用；新增个人背景、教学约定和学习目标的网页编辑保存。材料迁移已逐字节核对，网页编辑功能未运行测试或浏览器验收。**

2026-09-21：新增 C / Java 本机代码练习区。静态审阅不代表运行验证；按用户要求，本轮未运行测试、编译检查或浏览器验收。

## 已确定的方案

- 网页：HTML、CSS、JavaScript，聊天为主，学习记录按需展开。
- 本地程序：Python + FastAPI，提供网页、准备教学材料、调用模型并保存记录。
- 模型：第一版接入 DeepSeek API，具体模型和请求参数在实现时核对。
- 存储：教学材料用 Markdown，聊天、断点和学习观察用 JSON。
- 运行：启动一个本地程序，通过浏览器访问本机地址。
- 代码练习：聊天旁提供 Windows 本机 C / Java 单文件编辑与运行区；多文件项目仍使用外部工具。

本地保存不意味着完全离线：调用云端模型时，相关教学材料和消息会发送至模型服务。

## 使用与开发

### 日常使用：双击启动

这台电脑已安装依赖，直接双击仓库根目录的 **启动 Trae-Learning.cmd**。它会启动本地服务，准备好后自动打开浏览器；如果本应用已经运行，则直接打开网页，不启动第二份。

使用时保留启动窗口。关闭浏览器页面不会退出服务；彻底退出时在启动窗口按 Ctrl+C，或关闭该窗口。若启动失败，窗口会保留错误信息。如果提示端口被占用，请先关闭旧服务再启动，不会自动结束其他程序。

此入口使用已有的 .venv，不是独立安装包，也不会自动安装依赖。

### 首次安装与手动启动

需要 Python 3.12 或更新版本。当前支持从源码目录运行，尚未制作独立安装包。

在仓库根目录打开 PowerShell，首次安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

启动（之后只需执行这一条）：

```powershell
.\.venv\Scripts\python.exe -m app.main
```

打开 <http://127.0.0.1:8000>，点击右上角“设置”，填写自己的 DeepSeek API Key 并选择模型。密钥在本机 `.env` 明文保存，不提交 Git，也不会作为聊天内容发送；再次打开设置不显示旧密钥全文，留空表示保留原密钥。

当前支持官方文档列出的 `deepseek-flash`（默认）和 `deepseek-v4-pro`，使用普通回答模式，不启用思考模式。接口与参数依据 [DeepSeek 官方说明](https://api-docs.deepseek.com/) 和 [模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)。保存设置不会发起收费请求，也不代表密钥已经验证。发送聊天会调用你的 API 账户；没有自动付费重试。

输入问题后 Enter 发送，Shift+Enter 换行。生成时可以停止；失败后可重试最后一条未完成回答。重试保留原问题与旧回答片段，新增一次回答尝试。网页支持 Markdown、代码块复制，模型输出会经过清理。

点击左侧“＋ 新建对话”开始空白聊天；历史列表使用第一条问题的前 48 个字符作为标题，点击即可切回。当前已经是空白对话时直接复用，不重复制造空白记录。新建不删除旧聊天，也不清空教学规则或个人背景；模型只收到所选对话的已完成问答与当前问题，不混入其他聊天或残缺回答。不同对话仍共享同一套长期教学材料。

聊天分别写入 `data/conversations/session-<编号>.json`，最后选择的位置保存在 `data/current-conversation.json`；刷新页面或重启服务后恢复该对话。升级前的聊天文件直接保留并出现在历史列表中。当前尚无长对话压缩，超出服务限制会明确报错。

生成中请先停止回答再切换；保存失败时先重试保存。页面内切换会临时保留各对话未发送的草稿，刷新或关闭页面不保留草稿。暂不提供删除、重命名或同时生成多段回答。多个窗口共用当前选中的对话；旧窗口提交时会检查对话编号，发现已被其他窗口切换会拒绝发送并重新读取，避免写错对话。

问题先保存再调用模型，回答在完成、停止或失败时保存。若回答保存失败，页面保留内容并提供“重试保存”，修复前不继续发送。强制结束 Python 或断电时，正在生成的尚未落盘片段可能丢失，但原问题保留，重启将该回答标为中断。直接关闭聊天页会停止当前请求，尽量保存已收到的文字；这不能撤回服务端已产生的费用。

程序只监听本机地址，按单进程、同一会话一次生成设计，不支持同时启动多个实例写同一资料目录。终端按 Ctrl+C 停止服务。

验证：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

检查使用临时目录和模拟模型，会自动启停测试服务，不产生模型费用，也不写个人资料。具体范围见 [验证说明](tests/README.md)。

## 应用自己的学习材料

当前本机已将原项目的 10 份教学与个人材料完整迁至 `data/learning-materials/`，保留原文和目录结构。`data/learning-source.json` 使用相对路径 `data/learning-materials` 并标记 `managed: true`。之后应用只读写自己的材料，不再依赖原项目目录，也不与它同步。原项目作为历史来源保留原状。

右上角“教学材料”查看下一次请求的内容。展开“个人背景与偏好”“教学约定与已有词表”或“个人目标与约束”，点击“编辑并保存”，直接修改 Markdown 原文。保存后所有对话的下一轮发送或重试重新读取；已经开始的回答不受影响。其他七份材料只读，原学习证据和掌握判断仍作为历史依据，不自动更新。

编辑与保存不调用模型。保存核对读取版本，其他窗口修改后拒绝过期覆盖；文件原子替换，保存失败保留页面编辑并提示。关闭未保存编辑前提示确认，刷新/关闭可能丢失未保存内容。聊天中临时提出偏好不会自动变成长期约定。

每轮回答旁“本次教学材料”查看实际请求的快照，始终只读，后续修改不影响它。材料会随聊天发送给 DeepSeek；配置、材料读取或快照保存失败时明确报错，不静默回退。应用新断点仍保存在 `data/computer-breakpoint.json`，优先于迁入的历史 status，迁移不覆盖它。

迁移过程与准确范围见 [教学材料维护](docs/teaching-context.md)。个人材料、聊天、断点和快照全部在被 Git 忽略的 `data/` 中。迁往其他电脑需携带应用代码和自己的 `data/`，另行配置 Python、编译器和密钥；不再需要携带原学习仓库。独立安装包与新用户模板初始化尚未实现。

工程计划与交接可在独立工程仓库中管理，但应用运行代码、必要测试和使用说明应完整保留在本仓库，不依赖工程仓库运行。

## 计算机学习断点

在聊天标题旁打开“学习断点”，点击“整理学习断点”，核对并修改草稿后点击“保存断点”。整理会调用一次模型，保存不调用模型；普通聊天不会自动更新断点。页面显示来源对话、整理到第几条消息、后续未整理消息数量，并可展开来源聊天核对。

第一次整理参考原项目断点，之后参考应用最近保存的记录和当前对话。要求模型区分学生表现、老师讲解和未完成回答；草稿的判断仍需用户核对，程序不认证掌握程度。

正式记录保存在 `data/computer-breakpoint.json`。草稿未保存前只在内存与页面中，刷新或关闭页面会丢失编辑内容；保存失败保留旧记录和编辑内容，可重试。整理过程中使用“取消整理”明确停止；直接关闭网页不能保证立刻停止模型调用，整理最长等待 120 秒，且绝不会自动保存草稿。

每次只维护一份计算机学习主线断点。新草稿、聊天位置或已保存版本发生变化时，旧草稿不能直接覆盖新记录。原仓库文件不修改。每次普通聊天（包括重试）读取最新保存的应用断点，结合当前对话使用；没有应用断点时参考原项目断点。原教学材料仍保留原文，原断点作为历史背景。材料预览与每轮快照包含实际提供的断点正文、保存时间及来源；未保存草稿不参与教学，其他对话中未整理的消息不会自动带入。断点读取失败时提示错误并停止请求，不静默退回旧进度。

## 聊天旁的代码练习

重启应用后，点击聊天标题旁的“代码练习”。选择 C 或 Java，自己写或粘贴代码，提前填好标准输入，再点击“运行”。老师回答中的代码块可“放入练习区”，使用当前选择的语言；替换非空代码前会确认。编辑区支持 Tab 插入四个空格、Enter 延续缩进；Esc 后按 Tab 可离开编辑区。

- C：本机 PATH 中需有 GCC（gcc），按 C17 编译 main.c。
- Java：需安装完整 JDK，使 javac 和 java 可用；文件为 Main.java，使用 public class Main，不声明 package。没有第三方依赖安装。
- 缺少工具时页面提示，不自动安装，也不影响另一种语言。安装或调整 PATH 后重启应用，再重新读取练习区。
- 输入一次性提供给程序，随后输入流结束；这里不是交互终端。结果显示编译/运行命令、标准输出、标准错误和退出状态。输出在本次任务结束后显示，不逐字流式展示。
- 全服务同时运行一个任务，编译最多 30 秒、程序最多 10 秒，每阶段标准输出与错误合计最多 16 KiB；超过上限会截断输出并结束任务。点击“停止”结束本次进程树，运行中先停止再切换对话。关闭网页不会主动停止运行；可重新打开查看状态，任务仍受超时限制。
- 草稿按对话保存至 data/practice/<对话编号>.json，每种语言分别保留代码和输入。编辑停止 500 毫秒后自动保存；切换聊天或运行前等待保存完成。保存失败会保留页面内容并提示重试，关闭前留意保存状态。多窗口版本冲突不会直接覆盖已有记录。
- 每个对话只在服务内存中保留最近一次运行结果，重启服务后清空。编辑代码不改变那次运行快照。点击“把本次代码与结果放入聊天”，补充问题后自己发送；只有发送聊天才调用模型。发进聊天的记录随聊天保存，未发送内容仍遵循聊天草稿刷新丢失的边界。

这是本机代码运行区，不是安全隔离沙箱。程序以本机账户权限执行，可以访问其他文件和网络；临时目录、超时、输出限制以及 Windows Job Object 只用于管理本次执行及子进程生命周期。临时编译目录由系统临时目录创建，任务结束时清理；原学习项目不是编译或保存位置。不会自动运行老师给的代码，不以运行成功登记掌握。

本轮未执行程序、自动测试或浏览器验收，也未安装/实际验证本机 GCC 与 JDK。不能宣称运行和停止机制已经验收通过。

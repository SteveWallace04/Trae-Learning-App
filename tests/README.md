# 验证

## 2026-09-22 验证边界

新增 test_guidance.py：首次初始化、十份材料保留、课堂隔离、提案与应用、恢复与撤销、过期版本冲突、保存失败、停止重试及上下文范围。合计 55 项检查曾全部通过。

preview_guidance.py 是临时数据、模拟模型的浏览器验收入口，不产生模型费用。用户要求停止验证，最终提示措辞调整及干净安装未作通过声明；不要自动继续验证。三个真实模型合成案例只支持有限行为观察，不证明教学效果。

此前会话版本有 34 项自动检查，全部使用临时目录和模拟模型，不读写用户资料，也不调用付费 API。HTTP 检查启动独立端口的临时服务，并在结束时关闭。

覆盖范围：

- 新建/切换时对话消息隔离、教学要求保留、旧记录与材料快照可读，重启恢复最后选择；空白对话复用。
- 旧窗口不能写入其他对话；生成中、未保存时拒绝切换；文件或选择保存失败保留原对话；打开旧中断对话后可重试。

对话管理另经隔离网页验证：新建空白聊天、发送后标题更新、切回旧聊天、页面内草稿恢复、刷新后保持所选对话，以及桌面布局。

- 原文完整进入实际模型请求组装路径、原文件不改动、材料快照与请求一致且重启保留；重试重新读资料，历史快照不受影响。
- 材料配置无效、缺失、空白、编码错误或快照保存失败时不调用模型；旧回答不补造材料记录，未配置明确标记基础模式。

材料面板另经隔离网页验证：预览、展开原文、以纯文本显示 HTML 字符、模拟聊天后的材料入口、刷新后查看历史快照。测试不证明真实模型遵从教学规则或教学效果等同于原系统。

- 启动器识别本应用并复用、拒绝其他端口占用、等待就绪后打开浏览器；批处理在缺少环境时显示错误并返回失败。浏览器打开动作在自动检查中被替代，不自动弹出浏览器。

- 首页、CSS 和 JavaScript 可访问。
- 健康接口返回正常状态。
- 密钥路径、个人数据路径、仓库文件和向上访问路径不通过 Web 服务暴露。
- 密钥不回显、空值保留原密钥、非法设置不写入、跨站请求拒绝。
- 聊天流完成、原文落盘与新应用实例恢复。
- 停止和真实 HTTP 断开后保存片段，禁止并发生成。
- 重试复用问题且不把残缺回答带入模型上下文。
- 初始保存失败不调用模型，最终保存失败可重试且禁止继续生成。
- 意外中断记录恢复，原子替换失败保留旧文件。
- 模型响应完成标记、截断、认证错误及异常格式处理。

在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

浏览器另行在临时模型夹具下确认排版、设置、流式显示、代码复制、停止、重试与刷新恢复。模拟测试本身不证明真实 DeepSeek 账户能成功调用。另于 2026-09-19 核对用户配置后的 6 轮完整问答，服务重启恢复全部 12 条消息，无保存错误；未复制原文或密钥，也未额外发送收费请求。

当前 Starlette 对 TestClient 使用 HTTPX 会发出弃用提醒，测试仍通过；暂不为消除提醒增加另一个 HTTP 客户端依赖。

随功能实现检查：
- 聊天保存与程序重启后的恢复。
- 请求失败或生成中断时保留消息并标记真实状态。
- 断点只在整理成功后更新，能够识别尚未处理的新消息。
- 用户修正的记录在下一次请求中生效。
- 学习观察引用真实存在的消息。

常规测试使用合成资料和模拟模型响应，不调用付费 API；真实模型连通性单独验证。
必要测试留在本仓库，不能依赖私有工程仓库才能验证产品。

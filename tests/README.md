# 验证

当前有 3 项真实 HTTP 检查，自动启动独立端口的临时服务并在结束时关闭：

- 首页、CSS 和 JavaScript 可访问。
- 健康接口返回正常状态。
- 密钥路径、个人数据路径、仓库文件和向上访问路径不通过 Web 服务暴露。

在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

浏览器另行确认首页排版与连接状态。当前不验证尚未实现的聊天、保存和模型功能。

随功能实现检查：
- 聊天保存与程序重启后的恢复。
- 请求失败或生成中断时保留消息并标记真实状态。
- 断点只在整理成功后更新，能够识别尚未处理的新消息。
- 用户修正的记录在下一次请求中生效。
- 学习观察引用真实存在的消息。

常规测试使用合成资料和模拟模型响应，不调用付费 API；真实模型连通性单独验证。
必要测试留在本仓库，不能依赖私有工程仓库才能验证产品。

# 原项目教学材料接入

本步只实现原文读取、请求装配和可核对的快照。它是功能迁移的第一步，不代表已复制原 Agent 的工具能力或已证明教学效果相同。

## 本机配置

创建 `data/learning-source.json`，目录相对于应用根目录解析，也可填写绝对路径：

```json
{"root": "../Trae-Learning"}
```

该配置只在本机保存，不提交。程序不自动扫描电脑或猜测学生资料位置。源目录由使用者提供，内容会在发送聊天时交给 DeepSeek；预览不调用模型。

## 原文范围

| 原文件 | 用途 |
|---|---|
| core/teaching.md | 条件性教学判断、真实性要求、已有词表 |
| core/learner-model.md | 如何解释表现，避免把掌握估计变成门禁 |
| templates/probe-template.md | 练习与探针的活动参考 |
| docs/examples/excellent-probability-dialogue.md | 教学决策示例，包含历史对话和纠正，不冒充当前学生回答 |
| core/profile.md | 学生背景、自报与偏好 |
| core/goals.md | 目标与资源约束 |
| roadmap/main.md | 学习方向，不能替代当前进度 |
| progress/calibration.md | 支撑判断的历史学习证据 |
| progress/mastery.md | 原项目依据证据形成的判断 |
| progress/status.md | 原项目保存时的认知断点 |

不读开发用 AGENTS、工程记录、历史评估、密钥或全部仓库。校准和掌握记录一起提供，是为了不把断点里的结论变成无依据的判断。没有自动打开原文链接的能力；未提供的源码、历史记录或其他链接目标不能声称已读取。

## 技术适配

原文不做提炼和改写。`app/context.py` 在原文外单列实际能力说明：不能运行代码；不能修改文件或更新学习记录；示例不是本轮证据；原断点若已被当前聊天推进，不反复回到旧问题。这些说明可以在网页的“完整教学上下文”查看。

目前每次提供上述全部 10 份文件，避免未经验证地删减条件与示例。代价是更多输入用量；不静默压缩，超过模型限制则沿用明确报错。没有声称把全部原文放入就一定能保持相同教学效果。

## 每次发送

1. 校验问题与配置，读取此时的原文件。
2. 拼接教学上下文，再附上已完成问答和当前问题。
3. 先保存材料快照与问题，再发起模型请求。
4. 回答关联快照，完成、失败或停止都可回看；重试重新读取材料并保留旧尝试。

`data/contexts/<内容摘要>.json` 保存精确原文与实际教学上下文，内容相同时复用一个文件；会话消息只保存关联编号。摘要用于命名和复用，不是防篡改签名。预览不生成快照；快照不是第二份正式学习状态，程序不从快照继续维护画像或进度。

旧回答没有快照，不补造。快照缺失时明确提示；读不到原材料或写不下新快照时不调用模型。极端情况下，快照已写入而会话保存失败会留下未关联快照，但不会发起收费请求。

## 当前边界

原项目 `progress/` 仍是正式学习记录来源，应用只读。网页中的新学习过程尚不会自动回写；断点整理、教学风格更新、新会话与材料编辑继续分步讨论。

迁移电脑需携带源资料目录和应用数据，调整配置位置。公开代码不包含这些个人文件。`defaults/` 暂未参与此流程；没有来源配置时仍使用明确标记的基础聊天提示。

已用合成材料验证原文从文件到模型 HTTP 请求不变、源文件未改动、重试读取更新、历史快照保留、失败阻止调用，以及网页查看和刷新恢复。没有为本次验收发送真实个人资料到云端或新增付费请求；教学质量仍待真实使用观察。

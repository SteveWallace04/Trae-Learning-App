# 教学与个人材料维护

2026-09-21 起，当前本机材料由应用维护。原项目保留为历史来源，不写回、不继续同步。迁移保留全部原文，不代表已复制原 Agent 的工具能力或验证相同教学效果。

## 一次迁移与存放

已有外部来源的安装可在用户授权后运行 `.\.venv\Scripts\python.exe -m app.learning_materials`。迁移读取配置指定的下列 10 份文件，在应用 data 下暂存并逐字节核对，完整目录就位后才原子切换 data/learning-source.json：

```json
{"root": "data/learning-materials", "managed": true}
```

当前本机已经完成迁移。重复执行不覆盖已迁入的材料；目标目录存在而配置未切换时会停止，请先检查状态，不能直接覆盖。若最终配置保存失败，原配置仍在，完整副本留在目标目录待处理。未迁移的旧安装仍按旧配置只读使用外部材料，网页不开放编辑；未配置来源的安装保留基础聊天，不自动制造画像或推断水平。

## 原文范围

| 原文件 | 用途 |
|---|---|
| core/teaching.md | 条件性教学判断、真实性要求、已有词表 |
| core/learner-model.md | 如何解释表现，避免把掌握估计变成门禁 |

| docs/examples/excellent-probability-dialogue.md | 教学决策示例，包含历史对话和纠正，不冒充当前学生回答 |
| core/profile.md | 学生背景、自报与偏好 |
| core/goals.md | 目标与资源约束 |
| roadmap/main.md | 学习方向，不能替代当前进度 |

不读开发用 AGENTS、工程记录、历史评估、密钥或全部仓库。校准和掌握记录一起提供，是为了不把断点里的结论变成无依据的判断。没有自动打开原文链接的能力；未提供的源码、历史记录或其他链接目标不能声称已读取。

## 网页维护

“教学材料”的当前预览中，个人背景 profile、教学约定 teaching、学习目标 goals 可编辑；其余材料以及所有历史快照只读。接口使用三个固定标识，不接受任意文件路径。保存核对文件内容 SHA-256 版本，旧版本不覆盖新内容；原子替换文件，失败不清空页面编辑。未保存关闭前确认，刷新或退出有未保存内容时触发浏览器提示。普通聊天不会自动修改长期材料。

## 教学装配与历史

context.py 每次发送、重试及预览都读取当前配置所指的材料，保留原文。独立能力说明指出模型不能直接操作文件或执行代码，学生可使用 C/Java 练习区主动提供结果；历史示例不作为当前证据。程序附上最新应用断点（如有），迁入的 progress/status.md 仅为历史参考；当前实际对话决定接下来怎样教学。

准备材料后先保存 data/contexts/<内容摘要>.json 和问题，再调用模型。回答关联该轮精确材料与实际上下文，历史快照不修改、不补造。保存新版材料不会改变已开始的回答。快照不是第二份正式学习状态；读取或保存失败阻止请求，不静默回退。

## 独立与验证边界

迁移后运行不访问原材料目录；跨电脑携带应用 data 即包含材料、聊天、断点及快照，相对路径不需要原仓库。Python、编译器和密钥仍需配置，尚无独立安装包或空白用户初始化。

本轮已实际迁移 10 份材料并逐字节核对副本，未执行编辑接口测试、模型请求或浏览器验收。更早的原文接入检查属于历史版本，不能代替本次验证。没有修改原项目、更新学习判断或改写已有应用断点。

## 开工评估（2026-09-19）

现有方案适合本地单人使用，继续采用普通网页、一个 Python 服务和文件存储，无需新增数据库或 Agent 框架。

- 先验证本地启动和网页通信，再接模型，最后验证消息保存和重启恢复，避免一次交付过多行为。
- 恢复聊天与按认知断点续学分开验收，第一阶段不宣称已经实现第二阶段。
- 接入聊天时同时明确重试是否复用原消息、停止生成如何标记，以及写入失败如何通知用户。
- API 配置只由后端持有；设置页面不回传已有密钥全文。
- JSON 暂按单进程写入设计。第一版同一会话一次只允许一个生成请求，不支持多窗口同时发送。
- AI 内容显示为文本或经过安全处理的 Markdown，不直接把模型输出当 HTML 执行。
- 真实模型调用的验收需要用户在本地配置有效密钥；不要把密钥粘贴进开发对话。
- 当前只交付源码运行方式；独立安装包和数据迁移不属于第一阶段。

第一阶段分步：①本地启动与网页通信；②DeepSeek 设置、聊天和生成状态；③保存、恢复及失败处理。用户确认将②③合并交付最小可用流程。三步的代码与模拟验证已完成，已观察到真实聊天和重启恢复正常；使用体验持续打磨。

## 当前聊天边界

- 模型默认 deepseek-flash，可选 deepseek-v4-pro，普通回答模式；发送前准备简短编程教学要求和已完成的问答。
- 当前只维护一个持续会话。重试复用问题，保留旧尝试，只有最后一条未完成回答能重试。
- 模型 API 使用 HTTPX；没有自动重试。等待超时、认证失败、余额不足及回答截断均保留问题并显示提示。
- 普通关闭页面或点击停止会取消生成并保存片段；强制结束进程只保证此前已落盘的内容，重启标记未完成回答。
- 初始写入失败不调用模型。最终写入失败保留内存内容并禁止继续发送，用户可以重试保存。
- 密钥写本机 .env；设置接口只返回是否已配置，不回显旧密钥。跨站网页请求及未知 Host 被拒绝。
- Markdown 使用本地固定版本的 marked 与 DOMPurify；不允许脚本、图片或表单进入回答页面。无需前端构建工具。
- 教学资料模板尚未初始化或读取，不宣称当前具有完整个性化教学或断点续学能力。

## 需求与对应功能

| 需求 | 功能 |
|---|---|
| 打开就能学 | 网页聊天，程序准备教学材料 |
| 停下还能接上 | 保存断点，新会话按断点继续 |
| 教学方式可调整 | 保存并读取个人教学偏好 |
| AI 的判断可纠正 | 展示和修改学习记录，关联原始消息 |
| 资料由用户持有 | 本地文件保存、备份和迁移 |
| 成果可展示 | 完整演示学习、保存、关闭和续学 |

## 数据约定

- Markdown：教学原则、个人背景、学习目标。
- JSON：会话原文、当前断点、值得保留的学习观察。
- 每次会话单独保存；消息有编号，观察引用对应原始消息。
- 断点记录已经处理到哪条消息，便于识别尚未整理的对话。
- 聊天自动保存，断点按需整理；整理失败保留旧断点和原始聊天。
- 写入新内容完成后再替换旧文件。具体格式与实现时一起确定。
- defaults/ 是初始化模板；data/ 是用户实际资料，不同时维护两份学习状态。
- API 密钥独立于学习资料保存，不进入 Git 或聊天导出。

## 第一阶段：聊得起来

交付：本地启动入口、聊天网页、DeepSeek 设置、逐段显示回答、自动保存和恢复最近聊天。
界面：聊天主页面、设置面板、失败与中断提示。
验收：配置模型后真实聊天；重启后找回记录；粘贴代码正常显示；请求失败保留问题。
边界：恢复聊天不等于已实现认知断点续学，不展示尚无功能的断点按钮。
具体模型、接口参数和依赖版本在实现前核对官方资料。

## 第二阶段：接得上

交付：读取教学材料、整理并展示断点、新会话续学。
验收：暂停学习并保存，重新打开后从未解决的问题继续；识别断点之后未整理的新消息。

## 第三阶段：改得动

交付：编辑断点与教学偏好、学习观察关联原始消息。
验收：纠正一条记录，后续教学使用修正内容；引用能定位到真实消息。

## 第四阶段：交得出去

交付：准确的启动说明、干净示例资料、必要检查、完整演示流程。
验收：新目录按 README 启动并完成示例。发布前决定许可证并检查个人资料与密钥。

## 暂不做

账号、云同步、多模型切换、自动掌握评分、复杂课程管理、内置代码执行、向量数据库和桌面安装包。

## 与旧仓库的关系

原仓库继续用于个人学习。仅将通用教学原则整理为默认材料，不导入个人词表、掌握判断和真实进度。
应用稳定后再决定个人资料迁移；迁移时明确正式记录的位置，不让新旧系统同时维护同一项进度。
工程仓库的产品路径和当前入口随本次实施切换到新应用；旧工程交付与测试属于历史原型，不作为新应用的能力或验证结果。

# Trae-Learning App

一个面向个人使用的 AI 编程学习应用，尝试让学习过程可以保存、继续，也可以由学习者调整教学方式。

**项目状态：v0.1 开发预览阶段。此处用于展示项目设计与进展，应用源码暂不公开，暂无公开下载版本。**

## 为什么做这个项目

用 AI 学编程时，聊天记录可以保留很多内容，但下一次打开对话，仍然需要回答几个问题：上次具体卡在哪里？哪些内容只是听过，哪些已经能自己解释？如果老师的讲解方式不合适，怎样让调整延续到后面的学习？

Trae-Learning 从个人学习需求出发，将课堂聊天、代码练习、学习断点和教学偏好维护放在同一个本地应用里。现阶段重点是把这些环节连接起来，逐步改善真实使用体验。

## 当前功能

| 功能 | 用户可以做什么 |
|---|---|
| 课堂聊天 | 创建与切换对话，接收流式回答，停止生成、重试失败回答，并恢复已保存的聊天 |
| 代码练习 | 在聊天旁编写单文件 C / Java 程序，提供输入，查看编译与运行结果，再主动把结果带回聊天 |
| 学习断点 | 根据当前讨论生成断点草稿，核对和修改后保存，供下一次学习参考 |
| 教学材料 | 查看与编辑个人背景、学习目标和教学约定，查看某轮回答实际使用的材料快照 |
| 学习指导 | 单独交流背景、方向和教学反馈，生成材料修改建议，查看差异后确认应用，必要时撤销最近一次应用 |

新用户的空白资料目录会初始化三份基础材料，不要求先填写完整背景才能开始交流。以上功能已有实现；整体仍处于开发预览阶段，最终完整验收尚未完成。

## 一次学习怎样展开

下面是预期使用流程的示意，不是真实学生案例或效果评测。

1. **提出问题**：例如“为什么这个指针表达式得到这样的结果？”
2. **自己尝试**：在练习区运行代码，把实际输出附到聊天中继续讨论。
3. **留下断点**：停止前整理当前疑问，核对后保存下一次继续的位置。
4. **继续学习**：下次打开应用，结合已保存断点和当前问题继续。
5. **调整教学方式**：如果讲解跳跃或追问过多，把相关片段交给学习指导，讨论希望怎样改变；确认提案后，后续教学读取新的约定。

## 几个重要的设计选择

### 长期调整由用户确认

“今天累了，直接告诉我答案”不一定意味着长期偏好改变。学习指导负责理解反馈、提出修改；应用展示修改理由、依据和新旧差异，用户确认后才保存。普通交流不会自动改写长期材料。

### 区分讲过、运行过和理解了

老师讲解过一个概念、程序成功运行、学生能够独立解释，是不同的事情。应用不把代码运行成功当作掌握认证，也不宣称能自动、准确地测量学习者能力。

### 保留可核对的来源

回答使用的教学材料保留请求快照；学习断点可以回看来源聊天。修改长期材料后，历史快照保持原样，便于理解当时的回答依据。

### 保持简单的本地结构

应用采用一个本地服务和普通文件存储。学习材料使用 Markdown，聊天、断点和修改记录使用 JSON。当前不引入账号系统、云同步或多 Agent 调度。

## 技术概览

| 部分 | 当前方案 |
|---|---|
| 界面 | HTML、CSS、JavaScript |
| 本地服务 | Python、FastAPI |
| 模型调用 | DeepSeek API |
| 数据保存 | 本地 Markdown / JSON 文件 |
| 代码练习 | Windows 本机 GCC / JDK，支持 C / Java 单文件程序 |
| 修改保护 | 材料版本核对、可恢复的多文件保存、最近一次修改撤销 |

学习指导与课堂聊天使用同一模型服务，通过不同的上下文和职责区分。材料维护指南参考 OpenAI 的 [Skills 编写建议](https://learn.chatgpt.com/docs/build-skills)与[提示工程建议](https://developers.openai.com/api/docs/guides/prompt-engineering)，并结合本项目的用户确认和学习证据原则整理；这不意味着项目获得官方认可或教学效果已被验证。

## 当前验证与边界

截至 2026-09-22，开发过程中有 55 项自动检查通过，使用临时资料和模拟模型，覆盖聊天、断点、指导提案、版本冲突及部分保存失败恢复行为。模拟浏览器也走通了指导交流、提案、应用和撤销流程；三个合成情境进行了真实模型核验。

这些结果针对当时的实现。之后有提示措辞调整，最终完整验收尚未完成，不能据此宣称稳定版就绪。少量模型案例也不构成学习效果证据。

- **本地保存不等于完全离线**：调用模型时，相关材料和消息会发送至 DeepSeek，并产生 API 使用费用。
- **代码练习不是隔离沙箱**：程序使用本机账户权限运行；超时和输出限制用于控制执行，不隔离文件或网络访问。
- **学习指导需要用户判断**：模型可能误解反馈，修改提案需要核对；系统不自动评定掌握程度。
- **支持范围有限**：面向本地单人使用，代码执行面向 Windows，尚无独立安装包及跨平台完整验收。

## 开发与后续方向

这是一个从个人学习需要出发、借助 AI 编程工具协作开发的项目。当前展示重点是需求取舍、功能实现和使用边界，不主张算法创新或已经证实的教学提升。

后续优先根据实际使用反馈完善新用户体验、指导建议质量和失败恢复。是否开放试用、公开源码及采用何种许可，将在范围确定后另行说明。
